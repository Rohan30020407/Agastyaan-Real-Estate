# Agastyaan Real Estate

A full-stack real estate platform for browsing and posting residential and commercial properties.

## Features

- Browse residential and commercial properties
- Property details and listings
- User authentication
- Property posting
- Buyer and tenant sections
- Commercial property section
- Backend API for handling application data
- Image and file uploads
- Responsive web interface

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- JSON
- Tailwind CSS
